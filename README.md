# PSArt + YourManager (bản thử 2026-10-25)

Hai plugin cho Photoshop trên Windows. Mỗi file zip có sẵn `CAI_DAT.txt` (tiếng Việt + English).

Tất cả bản tải: [Releases](https://github.com/DanhBoo/psart-plugin/releases)

## PSArt 1.5.0
**Tải: [PSArt_1.5.0.zip](https://github.com/DanhBoo/psart-plugin/releases/download/v2026.10.25/PSArt_1.5.0.zip)**

Bộ công cụ vẽ trong một panel: Layer Tools (tách layer, Export & Replace ảnh AI), Lineart (Extract Lines, nối / làm mượt nét),
Clean AI Image + Remove background, Perspective Grid (lưới phối cảnh, nắn nét theo lưới), và tab Codex (chat với Codex ngay trong
Photoshop, gửi vùng chọn, thay ảnh Codex vẽ vào layer). Các công cụ chạy ngầm, vẫn vẽ tiếp được.
Tab Codex cần Codex đã đăng nhập trên máy; không dùng Codex thì các tab khác vẫn chạy bình thường.
Cài đặt: [CAI_DAT_PSArt.txt](CAI_DAT_PSArt.txt)

## YourManager 0.3.2
**Tải: [YourManager_0.3.2.zip](https://github.com/DanhBoo/psart-plugin/releases/download/v2026.10.25/YourManager_0.3.2.zip)**

Quản lý version file Photoshop (.psd / .psb): mỗi file tự ghi bên trong nó thuộc dự án nào, version mấy, nên đổi tên /
chép / chuyển chỗ vẫn nhận ra. Danh sách version, mở / đổi tên / chuyển / xoá vào Thùng rác, Hoàn tác + Lịch sử, tìm PSD từ một ảnh.
Bản này chỉ có plugin Photoshop (`ptsplugin`). Giao diện mặc định English, đổi được sang tiếng Việt.
Không cần cài Python (tab Find có sẵn chương trình tìm ảnh trong plugin).
Cài đặt: [CAI_DAT_YourManager.txt](CAI_DAT_YourManager.txt)

---
Two Photoshop plugins for Windows (PSArt: drawing tools + a Codex chat tab; YourManager: file version manager for Photoshop). Install steps in English are in the second half of each `CAI_DAT` file.
